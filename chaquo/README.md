# chaquo — Chaquopy Python 运行时模块

通过 Chaquopy 嵌入 CPython，支持 Python 爬虫脚本运行。

## Python 依赖

| 包 | 用途 |
|---|------|
| `requests` | HTTP 请求 |
| `pycryptodome` | 加密 (AES/RSA/MD5) |
| `lxml` | XML/HTML 解析 |
| `beautifulsoup4` | HTML DOM 操作 |
| `pyquery` | jQuery 风格 HTML 选择器 |
| `ujson` | 高性能 JSON |
| `cachetools` | 缓存工具 |
